プライバシーポリシー

yt-autopilot（なまえの由来ラボの投稿ツール）

制定日: 2026年10月29日

1. 対象

本ポリシーは、YouTube チャンネル「なまえの由来ラボ」の運営者が、自分のチャンネルを運営するためだけに使う個人用ツール「yt-autopilot」（以下「本ツール」）に適用されます。本ツールは運営者以外のユーザーに提供しておらず、第三者のアカウントにはアクセスしません。

2. 本ツールが使う YouTube API サービス

本ツールは YouTube API サービスを使用しています。本ツールの利用により、YouTube 利用規約に同意したものとみなされます。Google によるデータの取り扱いは Google プライバシーポリシーをご確認ください。

3. アクセスする情報と目的

  • YouTube への動画のアップロードと管理（動画・サムネイル・字幕・再生リストの登録）: 運営者のチャンネルへ動画を予約投稿するため
  • YouTube Analytics の読み取り（再生回数・視聴維持率などの集計値）: 動画の改善に使うため

視聴者個人を特定する情報は取得しません。

4. 保存と共有

  • 認証情報（OAuth のトークン）は、運営者の GitHub リポジトリの暗号化されたシークレットにのみ保存します。
  • 取得した集計値は、運営者の非公開リポジトリに保存し、動画の改善にのみ使います。
  • 取得した情報を第三者に販売・共有・開示することはありません。

5. アクセス権の取り消し

本ツールへの許可は、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。取り消すと、保存された認証情報は使えなくなります。保存データの削除は下記の連絡先にご依頼ください。

6. 変更

本ポリシーを変更する場合は、このページで公開します。

7. お問い合わせ

GitHub Issues からご連絡ください。
